# VAISASTRAM — Environment Variable Reference

This document provides a complete dictionary of all supported environment variables.

---

## 1. Application & Rails Core

| Variable | Default (Dev) | Default (Prod) | Description |
| :--- | :--- | :--- | :--- |
| `RAILS_ENV` | `development` | `production` | Active Rails environment |
| `DATABASE_URL` | None (uses database.yml) | Required | Full PostgreSQL connection URL |
| `SECRET_KEY_BASE` | Auto-generated in dev | Required | Secret key for signed/encrypted cookies |
| `RAILS_MAX_THREADS` | `5` | `5` | Puma database pool and concurrency count |
| `RAILS_LOG_LEVEL` | `debug` | `info` | Active logging verbosity |
| `RAILS_FORCE_SSL` | `false` | `true` | Enforces SSL redirect and Secure cookie attribute |
| `RAILS_ASSUME_SSL` | `false` | `true` | Assumes SSL termination at reverse proxy |
| `PORT` | `3000` | `80` (container) | Port for Puma/Thruster listener |

---

## 2. AI Inference & Provider Routing

| Variable | Default | Description |
| :--- | :--- | :--- |
| `AI_PROVIDER_MODE` | `hybrid` (dev) / `cloud` (prod) | Options: `cloud`, `hybrid`, `local`. In production, defaults to `cloud` to avoid attempting to reach developer localhost Ollama. |
| `AI_PRIMARY_PROVIDER` | `openai` (or `gemini`/`ollama`) | Preferred primary provider: `openai`, `gemini`, `grok`, `groq`, `ollama`. |
| `AI_FALLBACK_PROVIDER` | `grok` (or `groq`) | Preferred secondary fallback provider: `grok`, `groq`, `gemini`, `openai`. |
| `AI_FALLBACK_ENABLED` | `true` | Automatically attempts fallback provider if primary inference fails or times out. |
| `AI_CLOUD_FALLBACK_ENABLED` | `true` | Backward-compatible alias for `AI_FALLBACK_ENABLED`. |
| `OPENAI_API_KEY` | None | OpenAI API key for GPT models. |
| `OPENAI_MODEL` | `gpt-4o` | OpenAI model identifier (e.g. `gpt-4o`, `gpt-4o-mini`). |
| `OPENAI_ENABLED` | `true` (if key set) | Explicit enable flag for OpenAI provider. |
| `XAI_API_KEY` | None | xAI API key for Grok models (also accepts `GROK_API_KEY`). |
| `XAI_MODEL` | `grok-2-latest` | xAI Grok model identifier. |
| `XAI_ENABLED` | `true` (if key set) | Explicit enable flag for xAI (Grok) provider. |
| `GEMINI_API_KEY` | None | Google Gemini API key. Used when provider is `gemini` or mode is `cloud`. |
| `GEMINI_MODEL` | `gemini-3.8-flash` | Gemini model name identifier. |
| `GROQ_API_KEY` | None | Groq API key for high-speed cloud inference and fallback. |
| `GROQ_MODEL` | `llama-3.3-70b-versatile`| Groq model name identifier. |
| `OPENROUTER_API_KEY` | None | OpenRouter API key for tertiary fallback. |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Base URL for local Ollama HTTP API. |
| `OLLAMA_MODEL` | `gemma3:4b` | Ollama model identifier. |
| `OLLAMA_TIMEOUT` | `90` | Timeout in seconds for local inference requests. |
| `OLLAMA_KEEP_ALIVE` | `5m` | Keeps Ollama model resident in VRAM. |

## 3. Storage & Solid Suite

| Variable | Default | Description |
| :--- | :--- | :--- |
| `SOLID_QUEUE_IN_PUMA` | `false` | Runs Solid Queue worker inside Puma process (dev only). |
| `POSTGRES_DB` | `vaisastram_production` | PostgreSQL database name used in container scripts. |
| `BACKUP_DIR` | `./backups` | Directory for automated PostgreSQL dumps generated by `bin/backup_db.sh`. |

---

## 4. Parameter Logging Scrubbing

The following keys are automatically scrubbed from logs via `config/initializers/filter_parameter_logging.rb`:
- `passw`
- `email`
- `secret`
- `token`
- `_key`
- `api_key`
- `api_secret`
- `authorization`
- `openai_api_key`
- `xai_api_key`
- `grok_api_key`
- `gemini_api_key`
- `groq_api_key`
- `openrouter_api_key`
